## 🔬 Course Labs Summary

### Lab 01: Transfer Learning & Deep Feature Extraction Benchmark
- **Objective**: Evaluated pre-trained CNN architectures (AlexNet, VGG16/19, ResNet18/50/101, DenseNet121, EfficientNet-B0) using fine-tuning transfer learning and deep feature extraction paired with machine learning classifiers (Logistic Regression, SVM, Random Forest, XGBoost, KNN, Decision Tree).
- **Key Findings**:
  - **Best Overall Accuracy**: Logistic Regression trained on deep features extracted from the top CNN backbone achieved **67.50%** accuracy (outperforming end-to-end models).
  - **Top Fine-Tuned Backbone**: ResNet50 and ResNet101 achieved **66.25%** accuracy among end-to-end transfer learning models.
  - **Most Efficient Model**: EfficientNet-B0 achieved **61.25%** accuracy with only **4.01M** parameters and **0.41 GFLOPs**.
